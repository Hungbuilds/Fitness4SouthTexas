Accessibility Statement

Last Updated: June 2026

Fitness4 is committed to making this website usable by as many people as possible, including people with disabilities. We've targeted the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA as the standard for this Site.

What We've Implemented

  • Descriptive alt text on meaningful images, and decorative elements hidden from screen readers
  • A semantic heading structure (one H1 per page, nested H2/H3 sections) so screen reader users can navigate by heading
  • Color combinations checked for sufficient contrast against this Site's dark background
  • A keyboard-navigable menu, including the mobile menu toggle
  • A fully responsive layout that works across phone, tablet, and desktop screen sizes
  • Reduced-motion support — scroll animations are disabled automatically for visitors with a system-level "reduce motion" preference set

Known Limitations

This Site is a newly built template and hasn't yet had a full third-party accessibility audit. The photo gallery currently shows placeholder tiles rather than real photography — once real images are added, each will need descriptive alt text written for it before launch.

Ongoing Effort

Accessibility is an ongoing effort, not a one-time fix. We welcome feedback — if you encounter a barrier using this Site, please let us know using the contact information below so we can address it.
